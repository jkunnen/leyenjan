# leyenjan.be

Website voor het stalen huwelijk van Leyla & Jan, vrijdag 2 juli 2027.

## Wat staat waar
- `index.html`: alle teksten van de site, per sectie (welkom, praktisch, inschrijven, nieuws)
- `style.css`: de huisstijl (kleuren, letters, bergkam)
- `rsvp.js`: het inschrijvingsformulier, dat doorstuurt naar de Google Form
- `assets/`: staaltextuur, deelbeeld voor WhatsApp, favicon

## Een nieuwsbericht toevoegen
Zoek in `index.html` naar `NIEUWS` en zet een nieuw `<article>` bovenaan de lijst.

## Belangrijk
Deze repo is publiek. Zet hier nooit adressen, telefoonnummers of gegevens van gasten in.
